# Feature modules

Các trang hiện tại là shell đầu tiên chuyển từ mockup sang React. Khi triển khai sâu hơn, tách component/state theo domain:

- `group/`: tạo nhóm, invitation và membership.
- `profile/`: skill profile phiên Lab.
- `assignment/`: AI draft, `CLARIFY`, override và approval.
- `progress/`: task status, blocked state và progress selector.
- `coach/`: dashboard và help request.
- `chat/`: P2, không được chặn working slice P0.

Mọi component visual mới hoặc thay đổi layout/CSS phải được Lê Thị Thùy Trang review.
